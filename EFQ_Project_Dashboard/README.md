# EFQ Project Dashboard

EFQ Project Dashboard is a local prototype for Enterprise Field Quality / Customer Complaint Incident Management. It is built with Streamlit and uses an Excel workbook (pandas + openpyxl) as the local datastore.

## Features

- Create incidents from a Streamlit form
- Store incidents in an Excel workbook (`data/EFQ_Dashboard.xlsx`)
- Search and filter incidents
- Edit and delete incidents (with confirmation)
- Activity logging for create/update/status/delete
- Dashboard with KPI cards and Plotly charts

## Installation

1. Create and activate a virtual environment (Windows example):

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Run the app:

```powershell
streamlit run app.py
```

## Excel schema

- incidents sheet columns:
  - IncidentID, Date, OEM, CustomerComplaint, DealerInfo, VehicleVariant, VehicleApplication, ECUPartNumber, Severity, IssueType, Custodian, Description, Status, CreatedAt, UpdatedAt

- activities sheet columns:
  - ActivityID, IncidentID, Action, User, Timestamp

The Excel file is created automatically at `data/EFQ_Dashboard.xlsx` on first run.

## Tests / Quick checks

- Start app: `streamlit run app.py` — app should load without errors
- Create an incident via `Create Incident` page — success message should appear
- Open `data/EFQ_Dashboard.xlsx` — new rows should appear under `incidents` and `activities`
- Manage Incidents page should show recorded incidents and allow edits/deletes
- Dashboard shows KPIs and charts

## Future migration

Design keeps business logic separated from storage so Excel operations can be replaced by an API + Firestore in future (React frontend, REST API / FastAPI backend, Firebase Authentication, Firestore, Firebase Storage).
